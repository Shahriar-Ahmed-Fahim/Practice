# Portfolio Website

## Description

This is a **personal portfolio website** built to showcase my skills, projects, and contact information.  
The website is fully responsive and demonstrates modern web development practices using **HTML5, CSS3, and Flexbox**.

---

## Features

- Semantic HTML structure for better accessibility and SEO
- Responsive layout for desktop, tablet, and mobile devices
- Navigation bar with smooth scrolling to sections
- Skills section highlighting technical expertise
- Projects section with clickable project links
- Contact form with proper labels and validation

---

## Tech Stack

- **HTML5** – Semantic markup for structured content
- **CSS3** – Styling, flexbox layouts, and responsive design
- **GitHub** – Version control and project hosting

---

## Lessons Learned

- Proper use of semantic HTML elements (`header`, `section`, `article`, `footer`)
- Flexbox layouts and spacing techniques
- Responsive design with container widths and media queries
- Structuring a professional portfolio page for clarity and usability

---

## How to View

1. Clone the repository or download the ZIP
2. Open `index.html` in a web browser
3. Navigate through the sections: Home, About, Skills, Projects, Contact
